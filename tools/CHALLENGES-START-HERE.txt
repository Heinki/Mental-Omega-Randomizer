MENTAL OMEGA CHALLENGES 1.44.5

Use a clean, writable Mental Omega 3.3.6 installation. Put the matching launcher
beside MentalOmegaClient.exe, gamemd.exe, and Syringe.exe. The source repository
does not include game data. A packaged EXE needs no separate Python installation.
Build and detailed feature instructions are in CHALLENGES_TESTING.md.

LOCAL PLAY
1. In Settings choose mission category challenge and Human players: 1.
2. Generate or continue a Classic, Mission List, or Grid run. All 22 challenges
   are available regardless of house. For every map in a new run, use
   All Campaigns, Mission goal 22, and no challenge exclusions.
3. Select an open challenge. Under Local challenge players choose Your house
   and Your color. Optionally enable Play with an AI teammate, then choose
   the AI house, a different color, and Easy/Normal/Hard difficulty.
4. Choose Game speed and click Launch Selected Mission. Local play needs no
   network or Archipelago connection. AI difficulty is independent of the
   enemies' challenge difficulty. The AI uses its native army.

Houses, colors, AI difficulty, and speed can change between matches without a
new seed. The launcher preserves selections and checks native map restrictions
before launch. Allies may share a house but need distinct permitted colors.
Challenges support Standard, Chaos, and Randomizer Arsenal rewards; challenge
Shop Mode and Archipelago seeds are not supported.

TWO HUMAN PLAYERS
Both PCs need matching game files, the same launcher version, and an authorized
private ZeroTier or Tailscale connection. Preserve an existing working route.
The launcher does not install, create, or join either network automatically.
See COOP_CONNECTION_GUIDE.md for network setup and troubleshooting.

Host:
1. Select challenge and Human players: 2; generate or continue a shared run.
2. Open Co-op Connection, choose Host, enter a player name, and connect.
3. Share the host's private-network IPv4 and displayed pairing code privately.
4. Choose a challenge house/color in the dialog and wait for the guest to join.
5. Select and launch an open challenge. The host controls progression,
   challenge difficulty, and pinned game speed for both players.

Guest:
1. Select challenge and Human players: 2, then open Co-op Connection.
2. Choose Join and a different player name. Enter the host's private IPv4
   without a subnet suffix, port, URL, or network ID, plus the pairing code.
3. Connect and choose a house/color in the dialog. The host supplies the run
   and shared rewards. Both humans must avoid the native AI name Computer.
4. Keep both launchers open and connected during play and result synchronization.

FIRST-TIME FIREWALL SETUP (Windows)
Use the supplied Setup-Private-Network.ps1 beside the EXE. When building from
source, copy it from tools/ into the game folder. Connect the private network,
then preview the helper from that folder:

  powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\Setup-Private-Network.ps1 -WhatIf

Apply with -Elevate and approve the Windows administrator prompt. The helper
allows this folder's launcher TCP 19420/19421 and gamemd UDP 1234 only on detected
ZeroTier/Tailscale adapters. It does not configure router forwarding. Run it
again after moving the game folder or changing the launcher filename. Use
-Launcher MentalOmegaRandomizer.exe to select a specific EXE when needed.

RESULTS AND UPDATES
Wins require verified native results; unfinished quits, crashes, and ambiguous
results award nothing. The surviving ally can finish after a human is eliminated.
A completed challenge grants its saved rewards once. Some score tables flush
only after leaving the native results screen.

Close the old launcher before replacing it or updating its shortcut. Preserve
RandomizerLauncherData, which contains the player's saves and settings. One-human
and two-human challenge saves are separate. Do not include private profiles,
connection histories, or pairing codes when distributing the launcher.

DIAGNOSTICS
Run MentalOmegaRandomizer.exe --self-check from the game directory. Confirm
RandomizerLauncherData/self_check.json shows app_version 1.44.5 and passed true.
For connection failures, check the private route, address, pairing code, and
firewall. While the host is listening, the guest can check the lobby port:

  Test-NetConnection -ComputerName HOST_PRIVATE_IPV4 -Port 19420

If the lobby connects but preparation fails, check TCP 19421. If both games
start but cannot connect, check UDP 1234 on both PCs. Retain the connection log,
RandomizerLauncherData/logs/launcher.log, and native debug/debug.log when reporting
problems, after reviewing private data. Installed-map and loopback audits do not
replace live verification of AI games, two-PC rewards, native abilities, and quit
recovery. See CHALLENGES_TESTING.md for validation scope and known limits.
